# Virtual Gardening Game 🌱 !!

A gardening simulation game developed as a final project for CSCI 125 using Java and the Processing library.

Plant and grow crops, manage changing weather conditions, harvest plants to earn points, and purchase additional seeds to keep your garden growing.

## Features

- **Crop Growth:** Plant and grow five types of crops: tomatoes, carrots, sunflowers, cabbages, and pumpkins.
- **Weather System:** Experience sunny, rainy, and dry weather that affects plant growth and watering.
- **Garden Management:** Plant seeds, water crops, harvest mature plants, and restore dead plots.
- **In-Game Shop:** Spend points to purchase additional seeds.
- **Progress Tracking:** Track the number of days played, points earned, and crops harvested or lost.
- **Custom Visuals and Interface:** Includes plant sprites, garden textures, weather icons, custom fonts, and an interactive game interface.

## Technologies

- Java
- Processing

## What I Learned

This project gave me experience organizing a Java application into multiple classes, implementing interactive gameplay, and managing game state. I worked with object-oriented programming, arrays, random events, graphical assets, and user input to bring the gardening simulation together.

## Project Structure

- `Main.java` — Main game loop, gameplay logic, weather, and player interactions.
- `Plant.java` — Plant growth stages and weather-dependent growth behavior.
- `Plot.java` — Garden plot states and plant rendering.
- `Shop.java` — In-game seed shop.
- `IntroScreen.java` — Intro screen and game instructions.
- `UIManager.java` — Game interface, inventory, weather display, and score tracking.
- `UIButton.java` — Reusable button functionality.
